# OpenAPI Generator 가 뭔데?
프론트 개발자는 백엔드의 API 명세를 보고 해당 API 를 어떻게 어떤 방식으로 사용하는지 확인 후 연동하는 작업을 하게 됩니다..

API 명세를 보는 편리한 방법 중 하나가 바로 **Swagger**라고 할 수 있습니다.

Swagger 도 충분히 API 명세 파일을 보는 것보다는 시각적으로 프론트에게 엄청난 편리함을 제공합니다.

그래도 저는 이제까지 요청이나 응답에 대한 타입을 직접 수동으로 작성해왔습니다.

이를 자동화 시켜주는 것이 **API Generator** 라는 도구입니다.

프로젝트의 수정사항이 생길 때마다 API 명세는 수정되며, 이는 결국 프론트에서도 요청이나 응답에 대한 내용을 수정해야 했습니다.

이는 수동으로 타이핑해서 생기는 휴먼 에러(오타, 필드 누락 등) 을 야기할 수 있습니다.

API 명세를 바탕으로 생성해주는 API Generator 도구를 이용하면 **휴면 에러**를 줄일 수 있으며, 싱크를 더욱 쉽게 맞출 수 있으며, API 수정사항이 생기더라도 **업데이트**만 하면 바로 반영하여 사용할 수 있다는 장점이 있습니다.

이는 프론트 개발자가 API 연동에 투자되는 시간을 줄여 **다른 기능 개발**에 더욱 집중할 수 있게 됩니다.
