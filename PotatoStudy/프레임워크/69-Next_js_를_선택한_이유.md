## Next.js 가 가지는 강점들
- React 대비 개발 편의성을 높이는 내장 기능들
- 손쉽게 구현 가능한 SSR, SSG
- 강력한 검색 엔진 최적화 SEO
- 위와 같은 강점들로써 이어지는 빠른 개발 속도 및 편리한 유지보수 환경 제공
- Vercel 과의 강력한 시너지로 인한 간편한 프론트 배포 가능

## Next.js 의 단점
모든 기술들이 그렇듯, Next.js 도 만능은 아니라고 생각합니다..

일단 제가 생각하는 단점으로는..

1. 유연성 제한
    - Next.js 는 내장 기본 기능들이 강력하여 사용하기 편하다!
    - 그래서 오히려 유연한 커스터마이징 하기 쉽지 않다!

2. 빌드 시간의 늘어짐
    - 프로젝트의 규모가 커질 수록 빌드 시간이 늘어난다!
   
3. 너무 작은 프로젝트에는 어울리지 않는다!
    - 간단한 CRUD 앱이라면 Next.js 가 제공하는 기능들이 오히려 과하다!
    - React 단독으로 프로젝트를 진행하는 것이 더 빠르고 간결할 수 있다!

4. 거의 표준으로 사용되는 프레임워크지만 생각보다 진입장벽이 높다..?
    - 위에서 언급한 Next.js 의 강점을 잘 활용하기 위해서 알아야 할 기술과 개념이 많다..
 
정도 라고 생각합니다..

그래서 저는 처음 프로젝트를 바로 Next.js 로 시작하는 것보다는 React 를 이용한 프로젝트를 한 번쯤은 경험하고 나서 시작해보는 것도 좋은 방법이라고 생각합니다!!


## 마치며..
자, 여기까지 왜 제가 '감기블' 프로젝트의 프론트엔드 프레임워크로 Next.js를 선택했는지 길다면 길고 짧다면 짧은 이유들을 짧막하게 풀어봤습니다!

'취업 하려구요!'라는 솔직한 마음에서 시작했지만, Next.js는 단순한 '취업 스펙'을 넘어 제가 꿈꾸는 큰 기업의 개발자로 가는 길에 반드시 마스터해야 할 핵심 도구이자, 저의 기술적 깊이를 한 차원 높여줄 든든한 동반자라는 확신이 듭니다!

'감기블'은 Next.js의 모든 강점들을 이용하여 고성능, SEO 최적화, 그리고 뛰어난 개발 생산성을 갖춘 기술 블로그가 될 겁니다. 물론 아직 Next.js의 모든 강점을 100% 활용하진 못했지만, 이 프로젝트를 통해 점진적으로 Next.js의 깊이를 파고들며 제 실무 역량과 프로젝트의 성능을 꾸준히 업그레이드할 예정입니다.

앞으로 Next.js를 '감기블'에 적용하며 겪게 될 수많은 삽질과(!) 성공 경험들, 그리고 그 과정에서 얻게 될 귀한 인사이트들을 이 공간을 통해 공유할 계획입니다! 
'감기블'의 발전에 많은 관심과 응원 부탁드립니다!
