안녕하세요! 
마크다운을 처음 접하시는 분들을 위한 **초보자 가이드**에 오신 것을 환영합니다! 

감자 기술 블로그는 글 작성 시 마크다운을 기반으로 작성하게 됩니다!

이 가이드는 **5분만에 빠르게** 마크다운의 핵심 기능들을 익힐 수 있도록 구성했어요.

---

## 📝 마크다운이 뭐예요?

마크다운은 **간단한 기호**로 예쁜 문서를 만들 수 있는 도구예요!
- HTML보다 훨씬 쉬워요
- 메모장에서도 작성 가능해요
- GitHub, 블로그 등 어디서나 사용할 수 있어요

---

## 1. 📑 제목 만들기

`#`의 개수로 제목 크기를 조절해요!

```markdown
# 가장 큰 제목 (보통 문서 제목)
## 큰 제목 (주요 섹션)
### 중간 제목 (하위 섹션)
```

**결과:**
# 가장 큰 제목 (보통 문서 제목)
## 큰 제목 (주요 섹션)
### 중간 제목 (하위 섹션)

💡 **팁**: 제목 앞뒤로 빈 줄을 넣으면 더 보기 좋아요!

---

## 2. ✨ 글자 꾸미기

중요한 내용을 강조할 때 사용해요!

```markdown
**굵은 글씨** - 중요한 내용
*기울인 글씨* - 강조하고 싶은 내용
~~취소선~~ - 잘못된 내용
`코드나 명령어` - 프로그래밍 관련
```

**결과:**
- **굵은 글씨** - 중요한 내용
- *기울인 글씨* - 강조하고 싶은 내용
- ~~취소선~~ - 잘못된 내용
- `코드나 명령어` - 프로그래밍 관련

💡 **팁**: 너무 많이 꾸미면 오히려 읽기 어려워져요!

---

## 3. 📋 목록 만들기

### 번호 없는 목록 (순서가 없을 때)

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 하위 항목 (앞에 공백 2개)
- 세 번째 항목
```

**결과:**
- 첫 번째 항목
- 두 번째 항목
  - 하위 항목 (앞에 공백 2개)
- 세 번째 항목

### 번호 있는 목록 (순서가 있을 때)

```markdown
1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계
```

**결과:**
1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계

💡 **팁**: 모든 숫자를 1로 써도 자동으로 1, 2, 3으로 바뀌어요!

---

## 4. 🔗 링크 만들기

다른 사이트나 페이지로 이동할 수 있게 해줘요!

```markdown
[링크에 보일 텍스트](실제 주소)
[네이버로 이동](https://naver.com)
[구글로 이동](https://google.com)
```

**결과:**
- [네이버로 이동](https://naver.com)
- [구글로 이동](https://google.com)

💡 **팁**: 링크 텍스트는 "여기 클릭" 보다는 "사용법 보기" 처럼 구체적으로 써주세요!

---

## 5. 💻 코드 작성하기

### 문장 중간에 코드

```markdown
`console.log("안녕하세요!")` 이렇게 코드를 넣을 수 있어요.
`Ctrl + C` 키를 눌러서 복사하세요.
```

**결과:**
- `console.log("안녕하세요!")` 이렇게 코드를 넣을 수 있어요.
- `Ctrl + C` 키를 눌러서 복사하세요.

### 여러 줄 코드

````markdown
```javascript
function sayHello() {
  console.log("안녕하세요!");
}
```
````

**결과:**
```javascript
function sayHello() {
  console.log("안녕하세요!");
}
```

💡 **팁**: 백틱 3개(```) 뒤에 언어 이름을 쓰면 예쁜 색깔로 표시돼요!
