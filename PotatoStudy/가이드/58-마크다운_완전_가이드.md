안녕하세요! 
마크다운을 처음 접하시는 분들을 위한 완전 가이드에 오신 것을 환영합니다! 🎉

이 가이드를 통해 마크다운 문법을 완전히 마스터하고, 전문적이고 읽기 좋은 문서를 작성해보세요. 마크다운은 배우기 쉽고 빠르게 문서를 서식화할 수 있는 강력한 도구입니다.

## 📝 마크다운이란?

마크다운(Markdown)은 텍스트 기반의 마크업 언어로, 간단한 문법을 사용해 서식있는 문서를 작성할 수 있게 해주는 도구입니다.

### 왜 마크다운을 사용해야 할까요?

- **간편성**: HTML보다 훨씬 간단한 문법
- **가독성**: 작성한 그대로도 읽기 쉬움
- **범용성**: GitHub, 블로그, 위키 등 대부분의 플랫폼에서 지원
- **빠른 작성**: 키보드만으로 빠른 문서 작성 가능
- **버전 관리**: Git과 같은 도구와 완벽 호환
- **학습 용이성**: 몇 가지 기본 문법만 익히면 바로 사용 가능

## 1. 📑 헤더 (Headers) - 문서의 제목과 구조 만들기

헤더는 문서의 구조를 잡는 가장 중요한 요소입니다. `#` 기호의 개수로 헤더의 크기를 조절할 수 있습니다.

```markdown
# 헤더 1 (가장 큰 제목)
## 헤더 2 (큰 제목)
### 헤더 3 (중간 제목)
#### 헤더 4 (작은 제목)
##### 헤더 5 (더 작은 제목)
###### 헤더 6 (가장 작은 제목)
```

**결과:**
# 헤더 1 (가장 큰 제목)
## 헤더 2 (큰 제목)
### 헤더 3 (중간 제목)
#### 헤더 4 (작은 제목)
##### 헤더 5 (더 작은 제목)
###### 헤더 6 (가장 작은 제목)

**💡 초보자 팁**: 
- 문서 제목에는 헤더 1을 하나만 사용하세요
- 헤더는 순서대로 사용하는게 좋습니다 (1→2→3)
- 헤더 앞뒤로 빈 줄을 넣으면 더 보기 좋아요

## 2. ✨ 텍스트 꾸미기 (Text Formatting) - 중요한 내용 강조하기

글자를 굵게, 기울이게, 취소선 등으로 꾸밀 수 있습니다.

### 기본적인 텍스트 꾸미기

```markdown
**굵은 글씨** - 중요한 내용
*기울인 글씨* - 강조하고 싶은 내용
~~취소선~~ - 잘못된 내용이나 더 이상 필요없는 내용
***굵고 기울인 글씨*** - 매우 중요한 내용
```

**결과:**
- **굵은 글씨** - 중요한 내용
- *기울인 글씨* - 강조하고 싶은 내용
- ~~취소선~~ - 잘못된 내용이나 더 이상 필요없는 내용
- ***굵고 기울인 글씨*** - 매우 중요한 내용

### 추가 꾸미기 방법

```markdown
<u>밑줄</u> - HTML 태그 사용
<mark>하이라이트</mark> - 형광펜 효과
`코드나 명령어` - 프로그래밍 코드나 컴퓨터 명령어
```

**결과:**
<u>밑줄</u> - HTML 태그 사용
<mark>하이라이트</mark> - 형광펜 효과
`코드나 명령어` - 프로그래밍 코드나 컴퓨터 명령어

**💡 초보자 팁**:
- 너무 많이 강조하면 오히려 읽기 어려워져요
- 일관성 있게 사용하세요 (예: 중요한 건 항상 **굵게**)
- 코드나 파일명은 백틱(`)을 사용하세요

## 3. 📋 목록 만들기 (Lists) - 내용을 깔끔하게 정리하기

### 번호 없는 목록

`-`, `*`, `+` 중 아무거나 사용할 수 있어요. 하나로 통일해서 쓰는 게 좋습니다.

```markdown
- 첫 번째 항목
- 두 번째 항목
  - 하위 항목 2-1
  - 하위 항목 2-2
    - 더 아래 항목
- 세 번째 항목

* 별표로 만든 목록
+ 플러스로 만든 목록
```

**결과:**
- 첫 번째 항목
- 두 번째 항목
  - 하위 항목 2-1
  - 하위 항목 2-2
    - 더 아래 항목
- 세 번째 항목

### 번호 있는 목록

```markdown
1. 첫 번째 단계
2. 두 번째 단계
   1. 하위 단계 2-1
   2. 하위 단계 2-2
3. 세 번째 단계

1. 숫자는 자동으로 순서가 맞춰집니다
1. 모두 1로 써도
1. 1, 2, 3으로 표시됩니다
```

**결과:**
1. 첫 번째 단계
2. 두 번째 단계
   1. 하위 단계 2-1
   2. 하위 단계 2-2
3. 세 번째 단계

### 체크리스트 (할 일 목록)

```markdown
- [x] 완료한 일
- [ ] 아직 안 한 일
- [x] 이것도 완료함
- [ ] 할 일 목록
```

**결과:**
- [x] 완료한 일
- [ ] 아직 안 한 일
- [x] 이것도 완료함
- [ ] 할 일 목록

**💡 초보자 팁**:
- 순서가 중요하면 번호 있는 목록을 사용하세요
- 단순 나열은 번호 없는 목록이 좋아요
- 체크리스트는 할 일이나 확인 사항 정리에 유용해요

## 6. 💻 코드 작성하기 (Code) - 프로그래밍 코드 예쁘게 표시하기

### 문장 중간에 코드 넣기

```markdown
`console.log("안녕하세요!");` 이런 식으로 코드를 문장 중간에 넣을 수 있어요.
`Ctrl + C` 키를 눌러서 복사하세요.
변수 `userName`에 사용자 이름을 저장합니다.
```

**결과:**
- `console.log("안녕하세요!");` 이런 식으로 코드를 문장 중간에 넣을 수 있어요.
- `Ctrl + C` 키를 눌러서 복사하세요.
- 변수 `userName`에 사용자 이름을 저장합니다.

### 여러 줄 코드 블록

백틱 3개(``)를 위아래로 써서 코드 블록을 만들어요. 언어 이름을 써주면 색깔이 예쁘게 표시됩니다.

```javascript

function sayHello(name) {
  console.log("안녕하세요, " + name + "님!");
}

sayHello("홍길동");
```

```python
# 파이썬 코드
def say_hello(name):
    print(f"안녕하세요, {name}님!")

say_hello("홍길동")
```

```html
<!-- HTML 코드 -->
<h1>제목입니다</h1>
<p>문단입니다.</p>
```

```css
/* CSS 코드 */
.highlight {
  background-color: yellow;
  padding: 5px;
}
```
````

**결과:**
```javascript

## 7. 💬 인용문 (Quotes) - 명언이나 중요한 말 강조하기

```markdown
> 이것은 인용문입니다.

> 여러 줄로 된

> 각 줄 앞에 > 기호를 붙이면 됩니다.

### 중첩 인용문 (인용문 안의 인용문)

```markdown
> 첫 번째 인용문
>
> > 두 번째 인용문 (더 안쪽)
> > 
> > > 세 번째 인용문 (가장 안쪽)
>
> 다시 첫 번째 인용문
```

**결과:**
> 첫 번째 인용문
>
> > 두 번째 인용문 (더 안쪽)
> > 
> > > 세 번째 인용문 (가장 안쪽)
>
> 다시 첫 번째 인용문

### 인용문 안에 다른 꾸미기

```markdown
> ## 인용문 안의 제목
> 
> **굵은 글씨**와 *기울인 글씨*도 쓸 수 있어요
> 
> ```javascript
> // 코드도 넣을 수 있어요
> console.log("인용문 안의 코드");
> ```
> 
> - 목록도 가능해요
> - 여러 가지 조합 가능
```

**💡 초보자 팁**:
- 중요한 말이나 정의를 강조할 때 사용하세요
- 다른 사람의 말을 인용할 때도 좋아요
- 주의사항이나 경고 메시지로도 활용 가능해요

## 8. 📊 표 만들기 (Tables) - 데이터를 깔끔하게 정리하기

### 기본 표

```markdown
| 이름 | 나이 | 직업 |
|------|------|------|
| 홍길동 | 25 | 학생 |
| 김철수 | 30 | 회사원 |
| 이영희 | 28 | 디자이너 |
```

**결과:**
| 이름 | 나이 | 직업 |
|------|------|------|
| 홍길동 | 25 | 학생 |
| 김철수 | 30 | 회사원 |
| 이영희 | 28 | 디자이너 |

### 정렬 옵션

```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:----------|:----------:|----------:|
| 왼쪽      |   가운데   |      오른쪽 |
| 내용 1    |   내용 2   |    1,000원 |
```

**결과:**
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:----------|:----------:|----------:|
| 왼쪽      |   가운데   |      오른쪽 |
| 내용 1    |   내용 2   |    1,000원 |

### 실용적인 표 예시

```markdown
| 기능 | 사용법 | 난이도 | 설명 |
|:-----|:------:|:-----:|:-----|
| **제목** | # ## ### | ⭐ | 문서 구조 만들기 |
| **굵게** | **텍스트** | ⭐ | 중요한 내용 강조 |
| **목록** | - 또는 1. | ⭐⭐ | 항목들 나열하기 |
| **표** | \| 기호 사용 | ⭐⭐⭐ | 데이터 정리하기 |
```

**💡 초보자 팁**:
- 표 제목은 명확하고 간단하게 적으세요
- 데이터가 많으면 표보다 목록이 나을 수도 있어요
- 스마트폰에서도 잘 보이는지 확인해보세요

## 11. 📝 초보자를 위한 작성 팁

### 좋은 문서 만들기

1. **제목부터 차근차근**: 큰 제목부터 작은 제목 순서로
2. **한 문단 한 주제**: 너무 긴 문단은 나누어서 쓰기
3. **적절한 강조**: 정말 중요한 것만 굵게 표시
4. **예시 들기**: 어려운 내용은 쉬운 예시와 함께

### 읽기 쉬운 글 쓰기

- **짧은 문장**: 한 문장에 하나의 내용만
- **빈 줄 활용**: 내용이 바뀔 때마다 빈 줄로 구분
- **일관된 스타일**: 같은 종류의 내용은 같은 방식으로
- **독자 생각하기**: 읽는 사람이 이해하기 쉽게

### 실수하기 쉬운 부분들

❌ **잘못된 예시:**
```markdown
#제목앞에공백없음
**굵게 **공백위치틀림
- [ ]체크박스공백빠짐
|표|에서|공백|이|없음|
```

✅ **올바른 예시:**
```markdown
# 제목 앞에 공백 있음
**굵게** 공백 위치 맞음
- [ ] 체크박스 공백 있음
| 표 | 에서 | 공백 | 이 | 있음 |
```

## 12. 🔍 자주 묻는 질문 (FAQ)

### Q: 마크다운을 어디서 사용할 수 있나요?
A: GitHub, 블로그, 위키, 메모 앱 등 정말 많은 곳에서 사용할 수 있어요.

### Q: 마크다운 파일 확장자는 뭐예요?
A: `.md` 또는 `.markdown`을 사용해요.

### Q: 색깔이나 폰트를 바꿀 수 있나요?
A: 기본 마크다운으로는 제한적이지만, HTML 태그를 함께 쓰면 가능해요.

### Q: 표가 제대로 안 만들어져요
A: 각 줄의 `|` 개수가 같은지, 빠진 공백은 없는지 확인해보세요.

### Q: 이미지가 안 보여요
A: 이미지 주소가 올바른지, 인터넷에서 접근 가능한 주소인지 확인해보세요.
