Toast UI Editor를 사용하여 멋진 기술 문서를 작성하고 계시는군요. 이 상세한 가이드를 통해 마크다운 문법을 완전히 마스터하고, 더욱 전문적이고 읽기 좋은 글을 작성해보세요. 마크다운은 배우기 쉽고 빠르게 문서를 서식화할 수 있는 강력한 도구입니다.

## 📝 왜 마크다운을 사용해야 할까요?

- **간편성**: HTML보다 훨씬 간단한 문법
- **가독성**: 작성한 그대로도 읽기 쉬움
- **범용성**: 대부분의 플랫폼에서 지원
- **빠른 작성**: 키보드만으로 빠른 문서 작성 가능
- **버전 관리**: Git과 같은 도구와 완벽 호환

## 1. 📑 헤더 (Headers) - 문서의 뼈대 만들기

헤더는 문서의 구조를 잡는 가장 중요한 요소입니다. `#` 기호의 개수로 헤더의 레벨을 조절할 수 있으며, 각 헤더 레벨마다 적절한 용도가 있습니다.

```markdown
# 헤더 1 (H1) - 문서 제목
## 헤더 2 (H2) - 주요 섹션
### 헤더 3 (H3) - 하위 섹션
#### 헤더 4 (H4) - 세부 내용
##### 헤더 5 (H5) - 상세 설명
###### 헤더 6 (H6) - 최하위 레벨
```

**💡 팁**: 
- H1은 문서당 하나만 사용하는 것을 권장
- 헤더 레벨을 건너뛰지 않고 순차적으로 사용
- 헤더 앞뒤로 빈 줄을 넣어 가독성 향상

## 2. ✨ 텍스트 강조 (Emphasis) - 중요한 내용 부각하기

텍스트에 의미를 부여하고 시각적으로 구분하는 다양한 방법들입니다.

### 기본 강조 방법

```markdown
**굵게 표시** - 매우 중요한 내용
*기울임꼴* - 강조하고 싶은 내용
~~취소선~~ - 더 이상 유효하지 않은 내용
***굵고 기울임*** - 극도로 중요한 내용
```

결과:
- **굵게 표시** - 매우 중요한 내용
- *기울임꼴* - 강조하고 싶은 내용
- ~~취소선~~ - 더 이상 유효하지 않은 내용
- ***굵고 기울임*** - 극도로 중요한 내용

### 추가 강조 방법

```markdown
<u>밑줄</u> - HTML 태그 사용
<mark>형광펜 효과</mark> - 하이라이트
`인라인 코드` - 코드나 명령어 강조
```

**💡 사용 팁**:
- 너무 많은 강조는 오히려 가독성을 해침
- 일관된 강조 규칙을 정해서 사용
- 코드나 파일명은 백틱(`)을 사용

## 3. 📋 목록 (Lists) - 정보를 체계적으로 정리하기

### 순서 없는 목록 (Unordered Lists)

`-`, `*`, `+` 기호를 사용할 수 있으며, 일관성을 위해 하나의 기호로 통일하는 것을 권장합니다.

```markdown
- 메인 항목 1
  - 하위 항목 1.1
  - 하위 항목 1.2
    - 더 깊은 하위 항목
- 메인 항목 2
- 메인 항목 3

* 별표를 사용한 목록
+ 플러스를 사용한 목록
```

### 순서 있는 목록 (Ordered Lists)

```markdown
1. 첫 번째 단계
2. 두 번째 단계
   1. 하위 단계 2.1
   2. 하위 단계 2.2
3. 세 번째 단계

1. 숫자는 자동으로 정렬됩니다
1. 모두 1로 써도
1. 순서대로 표시됩니다
```

### 체크리스트 (Task Lists)

```markdown
- [x] 완료된 작업
- [ ] 미완료 작업
- [x] 또 다른 완료된 작업
- [ ] 할 일 목록
```

**💡 활용 팁**:
- 단계별 가이드에는 순서 있는 목록 사용
- 기능 나열에는 순서 없는 목록 사용
- 체크리스트는 TODO나 요구사항 정리에 유용

## 12. 📝 작성 팁과 모범 사례

### 문서 구조화

1. **명확한 제목**: 독자가 내용을 쉽게 파악할 수 있도록
2. **목차 제공**: 긴 문서에는 목차를 통한 네비게이션
3. **적절한 헤더 레벨**: 논리적 계층 구조 유지
4. **단락 분리**: 한 단락은 하나의 주제만

### 가독성 향상

- **짧은 문장**: 복잡한 내용도 간단히 표현
- **적절한 여백**: 빈 줄을 활용한 시각적 구분
- **일관된 스타일**: 문서 전체에서 통일된 형식
- **예시 제공**: 추상적 개념은 구체적 예시로 설명

### 코드 문서화

```markdown
## 함수 설명

### `calculateTotal(items)`

**목적**: 장바구니 아이템들의 총 가격을 계산합니다.

**매개변수**:
- `items` (Array): 가격 정보가 포함된 아이템 배열

**반환값**: 
- `number`: 총 가격

**예시**:
```javascript
const items = [
  { name: '사과', price: 1000 },
  { name: '바나나', price: 500 }
];
const total = calculateTotal(items); // 1500
```

**주의사항**:
- 빈 배열이 전달될 경우 0을 반환
- 가격이 음수인 아이템은 제외
```

## 13. 🔍 문제 해결 가이드

### 자주 발생하는 문제들

**Q: 이미지가 표시되지 않아요**
A: 이미지 URL이 올바른지, 서버에서 접근 가능한지 확인하세요.

**Q: 코드 블록에 문법 하이라이팅이 안 돼요**
A: 백틱 3개 뒤에 정확한 언어 이름을 입력했는지 확인하세요.

**Q: 표가 제대로 정렬되지 않아요**
A: 각 행의 컬럼 수가 일치하는지, 파이프(|) 기호가 빠지지 않았는지 확인하세요.
